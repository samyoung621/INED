# 資料表格式

網站讀三個表：**球員**、**比賽**、**打席**。
所有數據（打擊率、上壘率、長打率、OPS、排行、走勢）都由網站從「打席」算出來，
**Google Sheet 裡不需要寫任何公式**。

三個表可以是同一份 Google Sheet 的三個分頁，也可以是 `data/` 底下的三個 CSV 檔。

---

## 1. 球員

| 欄位 | 必填 | 說明 |
|---|---|---|
| 背號 | ● | 球員代號，要跟「打席」表的背號對得起來。可以是數字也可以是英數字 |
| 姓名 | ● | 顯示用的名字 |
| 守備位置 | | 例：游擊、中外野 |
| 慣用手 | | 例：右、左、雙 |
| 狀態 | | 留空或「在隊」＝在隊；填「離隊」「退隊」的人預設不出現在成績表，但個人頁仍查得到 |

```csv
背號,姓名,守備位置,慣用手,狀態
1,陳建宏,投手,右,在隊
9,黃家豪,游擊,右,在隊
33,洪子翔,捕手,右,離隊
```

## 2. 比賽

| 欄位 | 必填 | 說明 |
|---|---|---|
| 場次 | ● | 比賽代號，例 `G01`。要跟「打席」表的場次對得起來 |
| 日期 | | `YYYY-MM-DD`。用來排序與顯示走勢，強烈建議填 |
| 對手 | | |
| 場地 | | |
| 我方得分 | | 兩個得分欄都填了才會算勝敗；留空表示還沒記分 |
| 對方得分 | | |
| 備註 | | 例：春季聯賽、友誼賽 |

```csv
場次,日期,對手,場地,我方得分,對方得分,備註
G01,2026-03-14,紅葉隊,青年公園壘球場,6,2,春季聯賽
G02,2026-03-28,大安獅,迎風河濱球場,4,6,春季聯賽
```

## 3. 打席

**一列 = 一個打席。** 這是整個網站的核心資料。

| 欄位 | 必填 | 說明 |
|---|---|---|
| 場次 | ● | 對應「比賽」表 |
| 局數 | | 數字，例 `3` |
| 背號 | ● | 對應「球員」表。也可以改填「姓名」欄 |
| 棒次 | | 打序，例 `4` |
| 結果 | ● | 見下方代碼表 |
| 打點 | | 這個打席打回幾分 |
| 得分 | | 這名打者**自己**最後有沒有回本壘得分，有就填 1 |
| 盜壘 | | 盜壘成功次數 |
| 盜壘失敗 | | |
| 得點圈 | | 打擊時二、三壘有人就填 `Y`，用來算得點圈打擊率。不填就不算這項 |
| 備註 | | 自由文字 |

```csv
場次,局數,背號,棒次,結果,打點,得分,盜壘,盜壘失敗,得點圈,備註
G01,1,3,1,GO,0,0,0,0,,
G01,1,14,2,SF,1,0,0,0,Y,
G01,2,23,3,2B,2,1,0,0,Y,追平安打
```

### 結果代碼

英文代碼、中文全名、中文簡稱都認得，混用也沒關係。

| 代碼 | 中文 | 簡稱 | 算打數 | 算安打 | 壘打數 |
|---|---|---|:--:|:--:|:--:|
| `1B` | 一壘安打 | 一安 | ● | ● | 1 |
| `2B` | 二壘安打 | 二安 | ● | ● | 2 |
| `3B` | 三壘安打 | 三安 | ● | ● | 3 |
| `HR` | 全壘打 | 全打 | ● | ● | 4 |
| `BB` | 四壞球 | 四壞 | | | |
| `IBB` | 故意四壞 | 故四 | | | |
| `HBP` | 觸身球 | 觸身 | | | |
| `E` | 失誤上壘 | 失上 | ● | | |
| `CI` | 妨礙打擊 | 妨擊 | | | |
| `K` | 三振 | 三振 | ● | | |
| `GO` | 滾地出局 | 滾出 | ● | | |
| `FO` | 飛球出局 | 飛出 | ● | | |
| `LO` | 平飛出局 | 平飛 | ● | | |
| `FC` | 野手選擇 | 野選 | ● | | |
| `DP` | 雙殺打 | 雙殺 | ● | | |
| `SF` | 高飛犧牲打 | 犧飛 | | | |
| `SH` | 犧牲打 | 犧打 | | | |

也接受這些常見寫法：`安打`→一安、`保送`→四壞、`SO`→三振、`短打`→犧牲打、`ROE`→失誤上壘 等等。
**認不出來的結果不會被默默忽略**，會出現在「設定 → 資料健檢」的警告裡。

## 數據怎麼算的

| 項目 | 公式 |
|---|---|
| 打席 PA | 所有打席列數 |
| 打數 AB | 打席 − 四壞 − 故意四壞 − 觸身 − 犧牲打 − 高飛犧牲打 − 妨礙打擊 |
| 安打 H | 一安 + 二安 + 三安 + 全壘打 |
| 壘打數 TB | 一安 + 2×二安 + 3×三安 + 4×全壘打 |
| 打擊率 AVG | 安打 ÷ 打數 |
| 上壘率 OBP | (安打 + 四壞 + 故四 + 觸身) ÷ (打數 + 四壞 + 故四 + 觸身 + 高飛犧牲打) |
| 長打率 SLG | 壘打數 ÷ 打數 |
| OPS | 上壘率 + 長打率 |
| 純長打率 ISO | 長打率 − 打擊率 |
| 三振率 / 四壞率 | 三振（四壞）÷ 打席 |
| BABIP | (安打 − 全壘打) ÷ (打數 − 三振 − 全壘打 + 高飛犧牲打) |
| 得點圈打擊率 | 標記得點圈的安打 ÷ 標記得點圈的打數 |

重點：
- **犧牲打（SH）不列入上壘率分母**，高飛犧牲打（SF）列入。這是正式記錄規則。
- **失誤上壘算打數但不算安打**，所以會拉低打擊率。
- 分母是 0 時顯示 `-`，不會顯示 `.000`，兩者意思不同。
- 全隊「合計」列是把所有打席加起來重算，不是各人率值的平均。

這些定義都有測試把關：`node --test tests/stats.test.js`。

## 規定打席

排行榜的率值類項目（打擊率、上壘率、長打率、OPS、純長打率、三振率、四壞率）
要達到規定打席才列入排名，避免「1 打席 1 安打 = 打擊率 1.000」霸榜。

預設 **規定打席 = 球隊場次 × 2**，可在「設定 → 規定打席係數」調整。
累計類項目（安打、全壘打、打點、得分、盜壘……）不設門檻。
