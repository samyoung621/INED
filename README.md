# 壘球隊打擊紀錄與排行

壘球隊打擊紀錄網站。資料放在 Google Sheet，**所有數據由網站計算**，試算表裡不用寫任何公式。

支援兩種資料來源：

- **球季累計成績** —— 一張表、每位球員一列的加總數字（上手最快）
- **逐打席** —— 三個分頁、一列一個打席（走勢、近況、單場成績表都算得出來）

```bash
python3 -m http.server 8000   # 然後開 http://localhost:8000/
```

第一次打開會顯示示範資料，接上自己的 Google Sheet 後即換成球隊實際紀錄。

## 功能

| 頁面 | 內容 |
|---|---|
| **總覽** | 戰績、團隊打擊成績、各項排行前 5 名、團隊打擊率走勢、打席結果分佈 |
| **排行榜** | 16 個項目的名次表與長條圖，率值類套用規定打席門檻 |
| **成績表** | 全隊 26 欄數據，可排序、搜尋、匯出 CSV，合計列為加總後重算 |
| **球員頁** | 個人累計、近況、累計打擊率走勢、打席結果分佈、逐場成績、逐打席、隊內名次 |
| **比賽** | 比賽列表與單場成績表（box score）、逐局紀錄 |
| **記錄** | 手機現場逐打席輸入，含本場即時統計，匯出 CSV 貼回 Sheet |
| **設定** | 接 Google Sheet、球隊名稱、規定打席係數、資料健檢 |

計算的數據：打席、打數、安打、一／二／三壘安打、全壘打、壘打數、打點、得分、
四壞、觸身、三振、盜壘、打擊率、上壘率、長打率、OPS、純長打率、三振率、四壞率、
BABIP、得點圈打擊率、長打、上壘次數、每場打點。

## 技術

純靜態網站，**沒有建置步驟、沒有執行時期依賴**：原生 JavaScript、原生 SVG 圖表、
自寫 CSV 解析。可直接部署到 GitHub Pages。支援淺色／深色模式與手機版面。

```
index.html
assets/js/
  stats.js     打擊數據計算引擎（純函式，同時供 Node 測試使用）
  data.js      CSV 載入、欄位對應、正規化、資料健檢
  charts.js    折線圖／長條圖（含十字準線與 tooltip）
  ui.js        可排序表格、數據磚等共用元件
  views/       七個頁面
data/          示範資料 CSV
docs/          資料格式與部署說明
tests/         數據定義測試
```

## 測試

```bash
node --test tests/stats.test.js
```

打數怎麼扣、上壘率分母含哪些、分母為 0 時回傳什麼，都有測試釘住。
